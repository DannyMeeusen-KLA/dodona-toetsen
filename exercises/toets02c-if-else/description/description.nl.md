Het programma vraagt aan de gebruiker om een geldig geheel getal in te brengen.  
Vervolgens drukt het programma het kleinste even getal af dat **groter** is dan het ingebrachte getal.  
  
  
### Voorbeelden

```console?lang=python&prompt=>>>
>>> 1
2

>>> 4
6

>>> -8
-6

>>> -11
-10

```
