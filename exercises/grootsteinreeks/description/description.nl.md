Je krijgt een programma dat het kleinste van <u>drie</u> getallen afdrukt.  
Pas dit programma op drie punten aan:  
- verbeter de fouten (als je het uitvoert in de sandbox zal het niet werken)  
- breid het programma uit zodat het programma het kleinste van <u>vijf</u> getallen afdrukt
- breid het programma uit zodat het programma het kleinste <u>en het grootste</u> van vijf getallen afdrukt. Bekijk de voorbeelden voor de correcte uitvoertekst.
  
Als je je programma indient, zal Dodona het volledige programma testen.

### Voorbeeld

```console?lang=python&prompt=>>>
>>> 65
>>> 25
>>> 55
>>> 45
>>> 35
Het kleinste getal is 25, het grootste getal is 65.
>>> -20
>>> -35
>>> -20
>>> -35
>>> -27
Het kleinste getal is -35, het grootste getal is -25.
>>> 80
>>> 80
>>> 80
>>> 80
>>> 80
Het kleinste getal is 80, het grootste getal is 80.
```
